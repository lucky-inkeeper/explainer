>How does Explainer work?
Great question! Explainer is a desktop application built with Electron that wraps an Excalidraw canvas and exposes a set of tools over the Model Context Protocol. When an MCP client such as Claude Code connects to the local server on port 7331, it receives instructions describing a notation in which every kind of element has its own shape and color: user actions are yellow ellipses, system steps are blue rectangles, decisions are orange diamonds, databases are green rounded rectangles, and external services are red rectangles with a thicker stroke. The agent then calls draw_elements with a batch of skeleton elements. Before the elements reach the canvas, the main process runs a notation check that compares each element with the rules and collects a list of warnings, for example a decision label that does not end with a question mark. After that, a layout pass routes the arrows, makes room for arrow labels, parks notes beside their elements and reports any remaining overlaps. Finally the renderer places the batch in free space and adds a legend strip under the frame. In addition, drawings are autosaved to disk with a history backup, and a single drawing can be shared through a public link on Vercel Blob...
